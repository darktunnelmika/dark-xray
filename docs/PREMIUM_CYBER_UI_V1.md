# DARK XRAY — Premium Cyber UI V1

هدف: ظاهر تیره، سایبری و پریمیوم با **خوانایی بهتر**؛ بدون تغییر هیچ API، مسیر Xray، حسابداری، سیاست کلاینت‌ها، شناسه نود یا ساختار ذخیره‌سازی.

## هویت بصری (Midnight Cyber)

- پس‌زمینه: `#050c11`، پنل: `#0d1a21`، پنل برجسته: `#11222a`
- متن اصلی: `#e6f4f2`؛ متن توضیحی: `#9ebbb7`
- اکشن اصلی: `#54e2ae`، تزئین سرد: `#79cee9`
- خطا: `#ff8294`، هشدار: `#ffce7b`؛ معنای این رنگ‌ها نباید تغییر کند
- شعاع سطح‌ها ۱۰ تا ۱۲ پیکسل؛ بدون جلوه نئون سنگین یا افکت چشمک‌زن
- فونت و جهت نوشتار (فارسی RTL / انگلیسی LTR) از تنظیمات فعلی پیروی می‌کند

## مرحله ۱ — Design System و Shell (این PR)

- فایل افزوده `web/premium-cyber-v1.css` فقط در انتهای cascade بارگذاری می‌شود
- منوی اصلی: active واضح، scroll سالم و حالت hover کنترل‌شده
- دکمه‌های اصلی/ثانویه/خطر، ورودی‌ها، کارت‌ها، جدول‌ها، وضعیت‌ها و پنجره‌ها هماهنگ می‌شوند
- منطق موبایل، ارتفاع جدول کاربران، لیست ۵۰۰+ کلاینت، ترتیب نمایش و فرم‌های اصلی دست‌نخورده می‌مانند
- focus-visible، reduced-motion، رنگ خطا/هشدار و فیلدهای checkbox/radio حفاظت می‌شوند

## مرحله ۲ — Layout & Information Architecture (PR جداگانه)

- منوهای Xray / Node / Restore / Representative از نظر تعداد کلیک، دسته‌بندی و تراکم اطلاعات ارزیابی شوند
- ناوبری موبایل و هدر بهینه شوند؛ هیچ گزینه‌ای زیر صفحه پنهان نماند
- نگهداری صفحه فعلی پس از Refresh و حفظ وضعیت ویرایش‌ها آزمون شود

## مرحله ۳ — Page Polish (PRهای مستقل)

- Nodes: کنترل‌ها، وضعیت زنده، سلامت و جزییات
- Inbounds/Hosts/SWAP: مسیرهای Direct، Tunnel، SWAP و وضعیت اتصال
- Clients/Restore/Groups: سطرهای فشرده، صفحه‌بندی و عملگرهای کاربردی
- Representative/Bot/Marketplace/Settings: فرم‌های کوتاه‌تر و برچسب‌های یکسان

## مرحله ۴ — Motion & QA

- انتقال‌های کوتاه و بسیار ظریف با رعایت `prefers-reduced-motion`
- بررسی viewportهای دسکتاپ، تبلت و موبایل + RTL و LTR
- مرور مسیرهای حساس: QR، کپی لینک، ساب، Update، Replace Node و ویرایش کلاینت
- تست‌های source / Node.js، سپس مرورگر و سلامت هاب در محیط عملیاتی

## راه بازگشت

پوسته فقط با **یک** link اضافه در `web/index.html` فعال است. با حذف همین link می‌توان فوراً به ظاهر قبلی برگشت؛ نیازی به rollback دیتابیس یا تغییر وضعیت Node/Client نیست.

برای نصب: کنترل هش فایل از `SHA256SUMS`، نسخه پشتیبان `index.html`، کپی فایل CSS، جایگزینی HTML و بررسی HTTP 200 و سلامت سرویس. فایل CSS از `/assets/` به شکل static سرو می‌شود و نیاز به ریستارت Xray ندارد.
