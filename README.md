# DARK XRAY 🖤

**پنل مستقل مدیریت Xray با رابط فارسی سایبری، نمایندگی و کنترل دسترسی.**

نسخهٔ مبنا: `0.6.0-standalone-lab`

> [!CAUTION]
> **بارگذاری اولیهٔ این مخزن کامل نشده است. فعلاً از این مخزن نصب نکنید.**
> اکنون ۲۲ مسیر از ۶۷ فایل بستهٔ اصلی حضور دارند؛ READMEهای فارسی و انگلیسی برای اعلام وضعیت ناقص تغییر کرده‌اند. سه فایل بک‌اند اضافه شده‌اند، ولی باقی بک‌اند، رابط `web/`، ابزارها، تست‌ها و گردش‌کار CI هنوز روی شاخهٔ `main` نیستند.

## وضعیت انتشار

در ادامهٔ انتشارِ ۱۲ سپتامبر ۲۰۲۶، این فایل‌ها بدون تغییر محتوای بسته ثبت شدند و هش Git آن‌ها با فایل اصلی تطبیق داده شد:

| فایل | بخش |
| --- | --- |
| `backend/auth.py` | نشست‌ها، TOTP و کلیدهای API محدود به سطح دسترسی |
| `backend/backup.py` | بکاپ رمزدار و بازیابی در مقصد جدید |
| `backend/core.py` | ذخیرهٔ تنظیمات و مدیریت مستقیم فرایند Xray |

ارسال فایل بعدی، `backend/dark_policy.py`، با این پیام ابزار انتشار متوقف شد:

```text
This tool call was blocked by OpenAI because we couldn't determine the safety status of the request.
```

این پیام به‌تنهایی علت دقیق خطا را مشخص نمی‌کند. فایل مسدودشده منتشر نشده است و بارگذاری کامل یا اجرای موفق GitHub Actions ادعا نمی‌شود. جزئیات در [PUBLISH-STATUS.json](PUBLISH-STATUS.json) ثبت شده‌اند.

## هدف پروژه

DARK XRAY با رابط، API، دیتابیس و حساب‌های خودش طراحی شده است؛ بدون نصب سنایی، توکن سنایی، ورود دوم یا نمایش صفحات پنل دیگری. Xray-core موتور جداگانهٔ اتصال است.

```text
DARK UI → DARK API / Access Control → DARK Database → Xray-core
                                              └→ IP guard (nftables)
```

بستهٔ محلیِ مبنا شامل مدیریت نمایندگان، مالکیت مشتری روی اینباند مشترک، سهمیه و دفتر مصرف مستقل، سیاست IP، ورود و TOTP، نصب اولیه و بکاپ رمزدار است. **وجود این بخش‌ها در بستهٔ محلی به معنی حضور کامل سورس آن‌ها در این مخزن یا تأیید عملکرد عملیاتی نیست.**

حتی پس از تکمیل انتقال، نسخهٔ ۰.۶ آزمایشی است. اتصال با Xray واقعی، مسدودسازی فایروال زنده، نصب روی VPS تازه و عملکرد زیر بار هنوز تأیید نشده‌اند. چندنود و برخی امکانات پیشرفته نیز ناتمام‌اند.

## بررسی مجدد بسته

بررسی اولیهٔ فایل‌های حساس و تطبیق چک‌سام‌های بسته موفق بود؛ این بررسی جای ممیزی امنیتی را نمی‌گیرد. در اجرای مجدد محلی، دو گروه کامل با مجموع ۱۰۶ تست موفق شدند. اجرای مجموعه هنگام گروه تست کنترل فرایند به سقف زمانی ۱۲۰ ثانیه رسید؛ بنابراین کل مجموعهٔ آزمون‌ها در این نوبت موفق اعلام نمی‌شود. هیچ آزمایش زندهٔ فایروال یا اتصال مشتری واقعی انجام نشد.

## فایل‌های فعلاً ثبت‌شده

معرفی فارسی و انگلیسی، تغییرات، راهنمای مشارکت و امنیت، اطلاعیهٔ اجزای ثالث، فایل نسخه، تنظیمات نمونه، فهرست وابستگی‌ها، فایل‌های جلوگیری از ثبت اطلاعات حساس، ورودی‌های نصب، تعریف سرویس‌ها و سه ماژول بک‌اند بالا.

**ورودی‌های نصب و ماژول‌های ثبت‌شده به فایل‌های باقی‌مانده نیاز دارند و فعلاً مستقل اجرا نمی‌شوند.** رمز، توکن، کلید خصوصی، گواهی و دیتابیس واقعی را در مخزن یا Issue قرار ندهید.
