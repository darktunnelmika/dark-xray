# DARK XRAY 🖤

**پنل مستقل مدیریت Xray با رابط فارسی سایبری، نمایندگی و کنترل دسترسی.**

نسخهٔ مبنا: `0.6.0-standalone-lab`

> **بارگذاری اولیهٔ این مخزن کامل نشده است. فعلاً از این مخزن نصب نکنید.**
> فقط صفحه‌های معرفی، تنظیمات نمونه و بخشی از ساختار نصب و سرویس‌ها ثبت شده‌اند. سورس اصلی `backend/`، رابط `web/`، ابزارها و تست‌ها هنوز روی شاخهٔ `main` قرار ندارند.

## وضعیت انتشار

در ۱۲ سپتامبر ۲۰۲۶، دسترسی نوشتن تأیید و ثبت README انجام شد. سپس ارسال دو فایل بک‌اند از طریق ابزار انتشار، در دو تلاش با این پیام متوقف شد:

```text

```

این پیام به‌تنهایی علت دقیق خطا را مشخص نمی‌کند. بارگذاری کامل یا اجرای موفق GitHub Actions ادعا نمی‌شود. مشخصات بستهٔ اصلی و وضعیت انتقال در [PUBLISH-STATUS.json](PUBLISH-STATUS.json) ثبت شده‌اند.

## هدف پروژه

DARK XRAY قرار است با رابط، API، دیتابیس و حساب‌های خودش اجرا شود؛ بدون نصب سنایی، توکن سنایی، ورود دوم یا نمایش صفحات پنل دیگری. Xray-core موتور جداگانهٔ اتصال است.

```text
DARK UI → DARK API / Access Control → DARK Database → Xray-core
                                              └→ IP guard (nftables)
```

نسخهٔ مبنای محلی شامل مدیریت نمایندگان، مالکیت مشتری روی اینباند مشترک، سهمیه و دفتر مصرف مستقل، سیاست IP، ورود و TOTP، نصب اولیه و بکاپ رمزدار است. **وجود این امکانات در بستهٔ محلی به معنی حضور کامل سورس آن‌ها در این مخزن نیست.**

حتی پس از تکمیل انتقال، نسخهٔ ۰.۶ آزمایشی است. اتصال با Xray واقعی، مسدودسازی فایروال زنده، نصب روی VPS تازه و عملکرد زیر بار هنوز تأیید نشده‌اند. چندنود و برخی امکانات پیشرفته نیز ناتمام‌اند.
